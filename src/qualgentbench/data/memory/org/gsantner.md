- [users-001] Users keep notes, to-do lists and Markdown documents as plain text files on the phone. <!-- src=human; confirmed=2026-11-17; seen=0; contra=0; basis=readme -->
- [users-002] Many users also open the same files in desktop editors or keep them in sync with sync apps such as Syncthing. <!-- src=human; confirmed=2026-11-17; seen=0; contra=0; basis=readme -->
